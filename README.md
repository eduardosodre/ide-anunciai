# ide-anunciai

Plataforma de networking religioso — conecta igrejas, ministros e profissionais.

## Documentação (OpenSpec / SDD)

A especificação está em **[docs/](docs/README.md)**. O desenvolvimento do código segue após validação da documentação.

- Stack: PHP (sem frameworks), MySQL, HTML, CSS, JavaScript.
- Segurança e LGPD tratados desde o MVP.
- Arquivo `database.php` não é versionado; use `database.php.example` como referência.
